How Abhyas works

A four-step practice loop

Safe to fail, targeted to improve, gated by demonstrated competency — not sessions completed.

1

Practice

A scenario from the teacher's own class, subject and language — curriculum-scoped.

2

Simulate

An AI student answers back, and pushes back, like a real child with real misconceptions.

3

Evaluate

A separate scorer grades against a fixed rubric, quoting the teacher's own words.

4

Retry

The next scenario targets the measured weakest skill — until mastery unlocks the level.

Simulate → Interact → Evaluate → Identify gaps → Improve → Practise again Persona isolation: the student who challenges you never grades you. Separate instructions, separate model calls — enforced by tests.
How teachers progress

One skill at a time — then integrate

L1

Accuracy

Facts and curriculum alignment

L2

Clarity

An explanation a child of that age can follow

L3

Misconceptions

Surface the belief before correcting it

L4

Questioning

Probing that invites curiosity, not guess-the-answer

L5+

Integrated

All competencies, weighted like a real lesson

~10 scenarios per level — curated against the rubric Fixed bar, flexible practice — passes across distinct scenarios unlock the level; retries are private NPST-aligned — experts set the standard; the AI cannot invent criteria
Evidence-based evaluation

Feedback from your own words

A separate scorer grades against an expert-set rubric and must quote the teacher verbatim. A convincing-sounding answer is never mistaken for competence.

What works today
  • Voice-first rehearsal — speech-to-text in, text-to-speech out
  • "Heard me correctly" gate — the teacher reviews the transcript before scoring
  • Offline queue — attempts sync idempotently when connectivity returns
  • Deterministic engine — same attempt, same result, online or offline
Honest by design
  • Runs with no API key — cloud models optional behind one interface
  • Attempts stay private; only k-anonymised cohort trends (n ≥ 5) are shared
  • 27 themes, day-night environments — the gameverse changes with your clock
  • CI gate blocks regressions unless AI–expert agreement stays inside thresholds
